# `/debug:deop`

The [command](../en.md) is used to debug, and can offer the specified players with administrator permission, without requiring the executor of the command having the permission.

## Syntax

- `/debug:deop [targets]`

## Parameters

### `[targets]`

[Entity selector](/documents/arguments/entity_selector/en.md). Only contains players. If the entity selector is not used, it can directly reference the name of a player not online.
