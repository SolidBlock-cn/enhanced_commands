# `checkerboard()`

此[方块函数](../zh.md)生成一个棋盘格的图案。

## 语法

- `checkerboard(<方块函数 1> [权重 1], <方块函数 2> [权重 2] ...)`
- `checkerboard(<方块函数 1> [权重 1], <方块函数 2> [权重 2] ... x <x> <y> <z> [偏移量])`
- `checkerboard(<方块函数 1> [权重 1], <方块函数 2> [权重 2] ... / <x> <y> <z> [偏移量])`
- `checkerboard(<方块函数 1> [权重 1], <方块函数 2> [权重 2] ... \ <x> <y> <z> [偏移量])`

方块函数至少要有 1 个。权重不能为负数，可以为 0，但各项的权重之和不能为 0，每项的权重未指定时，默认为 1。

列表最后的 `/ <x> <y> <z>` 等价于 `x <1/x> <1/y> <1/z>`。偏移量未指定时，默认为 0。
